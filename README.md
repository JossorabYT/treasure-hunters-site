# Treasure Hunters – Suivi des récompenses

Petit site de fan (non officiel) pour cocher les récompenses obtenues dans les coffres de Fortnite Treasure Hunters.
La progression est enregistrée dans le navigateur de chaque personne.

Publié avec GitHub Pages depuis `index.html`. Les images sont dans le dossier `images/`.
Les images des récompenses appartiennent à Epic Games.
